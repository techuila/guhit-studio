01Draw

Type the length.
The wall obeys.

Pick the wall tool, click a start point, then type 4000 and press Enter. The wall is exactly four metres. No dragging until it looks right, no cleanup pass later.

Close a loop and the room inside names itself and measures itself. Move any wall afterwards and the area follows, along with every dimension that was snapped to it.

02See

There is no export step and no second model to keep in sync. The 3D view is the plan, read the other way. Draw a wall and it is already there, three metres tall, with the light falling on it.

Materials and furniture come from a built-in library of CC0 assets from Poly Haven, Kenney and ambientCG. Lift the roof, cut the model at eye level, or walk a camera through a room to check a sightline.

03Ask

It proposes.
You approve.

Ask in English or Taglish. The copilot turns the request into the same typed commands the toolbar produces, runs them through the engine, and shows you the result as a ghost on the plan. Nothing is committed until you press Apply, and one undo reverts it.

It answers questions from the model itself, never from a guess. Ask for the floor area and you get the number the engine computed.

Or drive it from Claude Code.

The app serves an MCP endpoint on localhost while it runs. Add it once and your MCP client can open projects, draw rooms, hang doors, read areas and export a sheet, with the desktop window updating as it works. The model runs inside your client on your own subscription. GUHIT never sees a key and never calls a model.

Every call is translated into the same validated command the toolbar uses, is one undo step in the app, and is refused outright if the plan moved on.

claude mcp add --transport http guhit http://localhost:1450/mcp

Cursor and Codex read the same endpoint.

05Secure by design

Nothing leaves without you.

Files stay local

A project is a folder on your disk with a readable JSON model, snapshots, renders and underlays. There is no account, no sync and no server holding your drawings. Back it up the way you back up everything else.

Your key, your machine

If you use the in-app copilot, the Claude API key is stored in a private file on your computer and is never handed to the interface. Through MCP there is no key at all: your own client does the thinking.

Every AI edit is checked

The language model cannot touch geometry. It emits typed commands that the Rust engine validates and can refuse, with a plain reason. A door that does not fit its wall is not drawn, it is rejected.

Loopback only

The MCP server binds 127.0.0.1 and refuses any request whose Host header is not local, so a web page cannot reach it. Exports can only be written inside the app's own exports folder.

06Built for the Philippines

Set up the way
you already work.

Most drafting software asks a Filipino architect to undo its defaults before the first wall goes down. This one starts where local residential practice starts.

  • Metric first. Millimetres everywhere in the model, square metres for areas. Feet and inches are never guessed on import.
  • CHB defaults. 150 mm hollow block walls, 900 x 2100 doors, 1200 x 1200 windows on a 900 sill, 3000 mm levels.
  • Tropical roofs. Gable, shed and flat presets with deep eaves, and a ridge you can turn to either axis.
  • Local materials. Metal roofing, CHB render, plain cement finish and clay tile in the built-in library.
  • Taglish copilot. "Ilan ang kwarto at ano ang total floor area?" works as well as the English version.
  • Peso pricing to come. Free while the app is in development. Pricing, when it arrives, will be in PHP.
